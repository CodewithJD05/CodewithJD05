## 🚀 Featured Project

### 📚 Library Management System

**Full-Stack Library Management Application**

A practical library management platform developed using FastAPI, PostgreSQL, SQLAlchemy, and JavaScript, designed to handle real-world library operations through secure REST APIs.

**Key Features**

- 🔐 JWT authentication with refresh tokens and session management
- 👥 Super Admin, Admin, and Librarian role-based access control
- 📖 Book inventory and physical copy tracking with unique barcodes
- 🔄 Book borrowing, returns, and concurrency protection
- 💰 Student and faculty fine calculation with holiday handling
- 📅 Book reservation and waiting-list management
- 📧 Email notifications and due-date reminders
- 🗄️ Database migrations using Alembic
- 🧪 Automated API testing using Pytest
